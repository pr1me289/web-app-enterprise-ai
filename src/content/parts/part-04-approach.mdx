The approach has three load-bearing pieces:

1. **A governed document stack** with non-overlapping jurisdictions — PRD, Design Doc, Context Contract, Orchestration Plan, Agent Specs.
2. **A deterministic Python supervisor** that walks six pipeline steps with explicit gate conditions. Orchestration is code; reasoning is LLM.
3. **Hybrid agentic retrieval** — per-source dense (Chroma) + lexical (BM25) collections, row-targeted matrix retrieval, cross-encoder re-ranking, authority-weighted bundle assembly.

The agents themselves are small, tightly scoped LLMs governed by behavioral specs with strict DOs / DON'Ts, output contracts, and distinct blocked / escalated / complete output shapes. The output of the governance layer is not prose; it is executable context.
