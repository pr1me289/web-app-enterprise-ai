The design deliberately refuses the flashier options. No LLM supervisor. No swarm of autonomous agents. No single-index RAG over everything.

Instead: a plain Python state machine walks the pipeline through explicit gates. The Context Contract governs what each agent is allowed to see. Agent Specs govern how each agent behaves inside that bundle. Embedding is deliberately **non-uniform** — some sources are indexed, some are deliberately not, because "embed everything" is often the wrong answer.

I am intentionally using a practical hybrid agentic retrieval approach rather than a flashy autonomous one, because the goal is governed enterprise reliability and explainability — not novelty theater.
